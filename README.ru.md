Wraithgram собран на официальном исходном коде [Telegram iOS](https://github.com/TelegramMessenger/Telegram-iOS)
(13.1.2). Все его функции собраны в одном меню: **Настройки → Wraithgram**. Нативная версия для macOS в
разработке.

Wraithgram не связан с Telegram.

## Скачать

Сборки выкладываются на странице [Releases](https://github.com/SkyDeaD/wraithgram/releases):

- **iOS:** файл `.ipa`. Wraithgram нет в App Store, поэтому ставь его через программу подписи, например ESign
  или LCSign, со своим сертификатом. Он встаёт рядом с официальным Telegram.
- **macOS:** файл `.dmg`, когда выйдет версия для macOS.

## Функции

### Приватность

- **Режим призрака.** Читать сообщения и смотреть истории без отметок «прочитано» и «просмотрено»,
  скрывать «печатает» и другие статусы (запись голосового или кружка, отправка фото, выбор стикера…),
  быть не в сети или всегда в сети. «Читать при действиях» отмечает чат прочитанным, когда ты
  отвечаешь или ставишь реакцию. Исключения по чатам, папкам и типам чатов.
- Скрытие сообщений от заблокированных.
- **Отложенная отправка:** пауза перед отправкой текста и медиа.
- **Анонимный режим:** маска на камеру и изменённый голос одним нажатием.
- **Подмена:** показывать другой номер телефона, открывать другой профиль вместо выбранного. И то и
  другое — только на твоём устройстве.

### Сообщения

- **Удалённые и изменённые.** Удалённые сообщения остаются в чате, у изменённых сохраняются прежние
  версии. Исключения, автоочистка по давности, экспорт и импорт истории.
- **Обход ограничений:** копирование и скриншоты в защищённых чатах, сохранение исчезающих и
  одноразовых медиа, открытие спойлеров, обход ограничений контента, скрытие рекламы.
- **Отправка:** правила замены слов, антикапс, ответ с цитатой, анонимные стикеры, без «via @бот»,
  скрытие «Отправить как», отправка по Return.
- **Перевод:** Google, Telegram или системный переводчик, кнопка перевода на сообщениях, перевод перед
  отправкой, текст на фото.
- **Меню и жесты:** своё меню сообщения (переслать без автора, сохранить в «Избранное» или «Фото»…),
  двойное нажатие для редактирования, закладки.
- **Экспорт чатов:** один чат или весь аккаунт в HTML и JSON.

### Безопасность

- **Защита чатов:** код-пароль или Face ID на выбранные чаты, секретная папка, скрытие чатов на
  скриншотах и записи экрана.
- **Код-пароль:** больше вариантов автоблокировки, блокировка при каждом запуске, «заблокировать сейчас».
- **Аккаунты:** Face ID при переключении аккаунтов, отдельные настройки для каждого аккаунта, перенос
  настроек с другого аккаунта.

### Медиа и звонки

- **Голос:** смена голоса с пресетами и своим голосом (высота, тембр, реверберация, эхо…), эквалайзер,
  цитирование из расшифровки голосовых и кружков от Telegram.
- **Кружки и камера:** AR-маски в кружках и видеозвонках, студия масок, водяной знак на фото.
- **Звонки:** запись звонков, тихое выключение микрофона, саундборд, статистика во время звонка,
  звонки только по TCP, без просьб оценить звонок.
- **Загрузки и качество:** ускорение загрузки и отправки, большие фото, субтитры к видео по
  распознаванию речи.

### Оформление

- **Тема и фон:** AMOLED, разделители, затухание краёв, анимированный GIF-фон чатов и профилей, снег.
- **Сообщения:** шрифты (из iOS или свои), пузыри, галочки, стикеры.
- **Список чатов:** строки, свайпы, аватарки, папки.
- **Панели:** таббар, поле ввода, быстрые кнопки.
- **Иконки:** наборы иконок, бейдж под Dynamic Island.
- **Профиль и настройки:** ID, дата-центр, даты, какие пункты показывать в Настройках.

### Ещё

- **VPN по подписке:** подписки и серверы VLESS, Telegram ходит через твой сервер. Ядро Xray — отдельный
  фреймворк внутри приложения, загружается только при включённом VPN.
- **Фейковые подарки:** подарки в твоём профиле, которые видишь только ты.
- **Дополнительно:** встроенный Safari или другой браузер, картинка в картинке для YouTube, IP и api_id в
  сеансах, «Недавние действия» и «Администраторы» в меню, больше вариантов отключения звука и кэша, без
  предложений Premium.
- **Настройки Wraithgram:** язык, экспорт и импорт всех настроек, сброс.

Интерфейс на английском, русском, украинском и арабском.

## Сборка

Нужны Mac с Xcode и Python 3. Bazel `build-system/Make/Make.py` скачивает сам при первом запуске.

1. Склонируй репозиторий с сабмодулями:

   ```sh
   git clone --recursive -j8 https://github.com/SkyDeaD/wraithgram.git
   cd wraithgram
   ```

2. Создай файл конфигурации и впиши `api_id` и `api_hash` с [my.telegram.org](https://my.telegram.org):

   ```sh
   cp build-system/wraithgram-configuration.example.json build-system/wraithgram-configuration.json
   ```

3. Собери для симулятора:

   ```sh
   build-system/WGBuild.sh
   ```

   Своих профилей для симулятора не нужно: без `build-system/wraithgram-codesigning/profiles` скрипт берёт
   тестовые профили Telegram из `build-system/fake-codesigning` с продлённым сроком. Для этой сборки оставь
   `bundle_id` равным `ph.telegra.Telegraph`.

4. Собери IPA для iPhone. Чтобы подписать её на телефоне через ESign, LCSign или похожую программу:

   ```sh
   build-system/WGBuildResign.sh
   ```

   Результат — `build-output/ipa/Wraithgram-for-resign.ipa` с bundle ID `org.wraithgram.app`. Чтобы вместо
   этого подписать на Mac своим сертификатом и профилями, смотри
   [Подпись своими профилями](docs/ios/codesigning.ru.md).

Скрипты сборки привязывают Bazel к Xcode, выбранному через `xcode-select`, и накладывают патчи из
`build-system/WGPatches` на сабмодули `rules_apple` и `tgcalls`. Файл конфигурации, папки подписи и
результаты сборки — в `.gitignore`.

### Ядро VPN (по желанию)

```sh
Wraithgram/Features/Vless/Core/build-core.sh
```

Нужны Go 1.26 или новее и инструменты командной строки Xcode; при первом запуске скачивается
[Xray-core](https://github.com/XTLS/Xray-core). Без ядра приложение всё равно собирается, а экран VPN пишет,
что ядро не включено в сборку.

## Структура репозитория

```text
wraithgram/
├── Wraithgram/           код Wraithgram
│   ├── WGCore/           настройки, строки, журнал (общее, без интерфейса)
│   ├── WGHooks/          точки, через которые Wraithgram подключается к коду Telegram
│   ├── WGSettingsUI/     меню Wraithgram
│   ├── Features/         функции, по модулю на каждую
│   └── Strings/          переводы и инструменты для них
├── build-system/         скрипты сборки (WG*.sh), патчи, шаблон конфигурации
├── docs/ios/             гайды для iOS: подпись, обновление до нового релиза Telegram
└── Telegram/, submodules/, third-party/, …
                          Telegram iOS; лежит в корне, потому что этого требует его сборка на Bazel
```

Правки в файлах самого Telegram маленькие, помечены `// WRAITH:` и вызывают `WGHooks`. Новые релизы
Telegram накладываются патчем: смотри [Обновление до нового релиза Telegram iOS](docs/ios/upstream-sync.ru.md).
Как вносить изменения — в [Как вносить изменения в Wraithgram](.github/CONTRIBUTING.ru.md).
